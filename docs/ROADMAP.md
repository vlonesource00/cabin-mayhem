# Roadmap

## Phase 0 — complete enough for prototype work

Vite/Tauri baseline, TypeScript checks, CI, docs, Canvas bootstrap and local test tooling.

## Phase 1 — complete

Moving-aircraft technical proof: greybox cabin, host authority, local simulated client, cabin-relative force, grabbing, straps, turbulence, debug display and automated smoke checks.

## Phase 2 - current vertical

Automatic flight, passenger service, galley fire, coffee-machine repair, free host-authoritative two-player WebRTC rooms, a responsive airline-sitcom landing debrief and a Blender-authored static cabin GLB with procedural fallback and procedural Web Audio cabin sound snapshot-projected interaction animation and two Blender-authored skeletal rigs with 44 clips driven by a Three.js `AnimationMixer` are implemented. Next: complete the full manual service/two-browser playtest, review the authored clips in motion, then extend animation to world props.

## Phase 3

Cargo contracts, event director, route/weather, remaining passenger/prop production art, recorded/production audio, save/economy/upgrades, onboarding and hardened relay-backed networking.

## Phase 4

Accessibility/controller hardening, network stress, performance pass, build release pipeline and external playtest readiness.
